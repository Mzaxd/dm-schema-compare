# 达梦数据库结构差异对比工具

用于对比两个达梦数据库（测试环境和生产环境）之间的表结构和索引差异。

## 功能特性

- 自动提取两个数据库的所有模式、表、字段、索引信息
- 对比模式、表、字段、索引的差异
- 生成Excel格式的详细对比报告
- 支持排除系统模式
- 支持进度显示
- 反向同步：目标端（生产）被临时扩长的字段生成在**源端**执行的扩长 SQL，避免把目标端改短（见下文「长度反向同步」）

## 环境要求

- Python 3.7+
- 达梦数据库官方驱动 dmPython
- 网络可达的两个达梦数据库

## 安装步骤

### 1. 安装 dmPython 驱动

#### 方法一：在线安装（推荐）
```bash
pip install dmPython
```

#### 方法二：离线安装
从达梦数据库安装目录获取源码：
```bash
cd dmdbms/drivers/python/dmPython
python setup.py install
```

### 2. 安装项目依赖
```bash
cd script/dm_compare
pip install -r requirements.txt
```

## 配置说明

编辑 `config.ini` 文件，配置数据库连接信息：

```ini
[test_env]
# 测试环境数据库连接信息
host = 192.168.1.100
port = 5236
user = SYSDBA
password = your_password

[prod_env]
# 生产环境数据库连接信息
host = 192.168.1.200
port = 5236
user = SYSDBA
password = your_password

[options]
# 排除的系统模式（逗号分隔）
exclude_schemas = SYS,SYSDBA,CTISYS,SYSJOB,SYSAUDITOR

# 输出目录（相对于脚本路径或绝对路径）
output_dir = ./reports
```

## 使用方法

```bash
python dm_compare.py
```

## 输出报告

报告将保存为 Excel 文件，包含以下5个工作表：

### 1. 汇总概览
- 数据库连接信息
- 差异统计（模式/表/字段数量）

### 2. 模式差异
列出仅在某一环境存在的模式

### 3. 表差异
列出仅在某一环境存在的表

### 4. 字段差异
列出所有字段差异，包括：
- 新增字段
- 删除字段
- 类型变更
- 长度变更
- 精度变更
- 可空性变更
- 默认值变更
- 注释变更

### 5. 索引差异
列出所有索引差异，包括：
- 新增索引
- 删除索引
- 唯一性变更
- 索引类型变更
- 索引列或排序变更

## 长度反向同步

场景：生产环境因数据超长被临时扩了某字段长度（如 `VARCHAR(100)` → `VARCHAR(200)`），此时对比结果里目标端反而比源端长。原来的同步 SQL 会把目标端**改短**，非常危险。

处理规则：

- 字段差异为「长度变更」且**目标端更长**、两端类型一致时，判定为生产临时扩长，走**反向同步**：
  - 生成的 SQL 为 `ALTER TABLE <源端模式>.<表> MODIFY <字段> <目标端类型长度>;`，即把源端扩到目标端长度
  - 页面/Excel 的字段差异表新增「执行端」列（源端/目标端）和「同步建议」说明
  - 页面上执行选中 SQL 时按「执行端」自动路由：`源端` 行连源端库执行（dual 模式按 `source_env_*` 路由，legacy 模式用 `[test_env]` 单连接），`目标端` 行维持原行为
  - 模式名带映射时（如 `GASBASE:BASE`），反向 SQL 自动还原为源端实际模式名
- 源端更长的正常长度差异不受影响，仍按源端同步目标端
- 完整部署脚本（目标端执行）**不包含**反向项，头部会注明条数；侧边栏另提供「⬇ 下载反向同步脚本（在源端执行）」

## 注意事项

1. 确保两台数据库服务器网络可达
2. 确保数据库用户有DBA权限或足够的查询权限
3. 大量表对比可能需要较长时间
4. 默认排除系统模式，可根据需要调整

## 常见问题

### Q: 提示"未安装 dmPython 驱动"
A: 请先安装 dmPython 驱动，参考上面的安装步骤

### Q: 连接数据库失败
A: 检查以下项目：
- 网络是否可达
- 端口是否正确（默认5236）
- 用户名密码是否正确
- 数据库是否启动

### Q: 查询某些表时报错
A: 可能是权限不足，请确保数据库用户有DBA权限
